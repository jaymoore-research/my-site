dbSNP reference lane

Ways to hold dbSNP so that MungeSumstats looks up rs ids faster, in less RAM, and can be rebuilt for each new dbSNP release. Each branch is one storage approach. A turn is one change, then a screen: identical output to the SNPlocs packages on the edge-case and build-inference inputs, then a timed lookup of 1 million rs ids.

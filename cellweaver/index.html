01 / THE QUESTION

Which cell types connect
genes to disease?

Public single-cell data offer a growing resource for studying where genes are expressed. CellWeaver builds cell-type references to connect that expression with genetic risk.

The challenge is to turn many experiments into useful, interpretable reference populations. Cell labels, tissue context and the choice of background all affect the result.

This poster follows the path from public data to whole-body references, then checks marker consistency and explores genetic associations.

02 / FROM DATA TO REFERENCE

Build the reference.
Keep the biology in view.

  1. 01

    Collect

    Start with public single-cell RNA sequencing data reprocessed by scBaseCount.

  2. 02

    Annotate

    Use Pan-human Azimuth cell labels and retain high-confidence calls from human primary samples.

  3. 03

    Measure

    Build tissue–cell-type populations. Measure gene specificity relative to the reference background.

  4. 04

    Connect

    Use MAGMA to test associations between cell-type gene specificity and genetic risk.

An association can prioritise a cell type for study. It does not establish a causal role in disease.

REFERENCE DESIGN

How much detail
should a reference retain?

Broad, medium and fine cell labels change the number and size of reference populations. More detail also changes which biological targets can be assessed.

MARKER CONSISTENCY

Do expected markers
recover their cell types?

The top-3 score asks whether a marker’s expected cell type ranks among the three highest expression classes. The figure subtracts random expectation.

Each reference has different classes, genes and available markers. This exploratory check is not a matched atlas ranking or an estimate of individual-cell annotation accuracy.

What these results can and cannot show

The marker panel contains 1,937 genes assigned to 204 Cell Ontology classes. Only markers with an available exact target class are assessed in each reference.

Coverage, cohort composition, tissue scope and cell-type granularity differ between references. Marker source independence has not been established. These analyses check consistency and guide further evaluation; they do not prove that one atlas is universally better.

04 / WHAT COMES NEXT

A reference to build on.

Extend genetic risk cell-typing across more traits, while testing how reference design changes the conclusions.

Future directions in the poster include finer cell-type resolution, wider analysis of genome-wide association studies, and exploration of rare-disease applications.

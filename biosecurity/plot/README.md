# Scientific governance timeline

Public plotting code and the data used for the figure in the blog post.

Install `requirements.txt`, then run `python3 scripts/plot_governance_timeline.py` from this directory. Outputs are written to `output/`.

The figure covers 15 fields. Red marks a restriction in at least one mapped setting, including funding conditions and voluntary pauses; it does not indicate a worldwide ban. Sources and scope notes are included in the data and the HTML evidence table.

The published figure was generated on 6 November 2026.
